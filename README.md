# Auditoria de Segurança — Servidor Web Linux

Auditoria de segurança básica de um servidor Ubuntu Server
hospedando um servidor web Apache HTTP Server.

## Objetivo

Verificar a segurança básica do servidor e identificar possíveis
não conformidades relacionadas à exposição de serviços, acesso
administrativo, permissões dos arquivos web e atualização do Apache.

## Escopo

- Ubuntu Server
- Apache HTTP Server
- OpenSSH
- Diretório /var/www/html
- Serviços de rede expostos

## Critérios

- CIS Benchmark para Ubuntu
- Política interna de segurança

## Metodologia

1. Planejamento
2. Coleta de evidências
3. Análise dos achados
4. Relatório
5. Acompanhamento

## Ferramentas

- Nmap
- OpenSSH
- Apache HTTP Server
- Linux CLI
